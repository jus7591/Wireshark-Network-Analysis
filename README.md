# Wireshark Network Analysis

Hands-on network traffic analysis using Wireshark to investigate
common network protocols and TCP behavior.

## Objectives

- Analyze network traffic at the packet level using Wireshark
- Understand common network protocols and their roles in network communication
- Analyze DHCP address assignment and the DORA process
- Analyze DNS queries and responses
- Understand ARP address resolution
- Analyze ICMP Echo Requests and Echo Replies
- Analyze TCP connection establishment and the three-way handshake
- Analyze TCP connection termination using FIN/ACK
- Compare graceful TCP termination with TCP resets
- Analyze HTTP traffic and identify application-layer data
- Analyze HTTPS traffic and understand TLS encryption
- Understand private and public IPv4 addressing and NAT
- Analyze TTL, ICMP responses, and round-trip time using traceroute
- Understand IPv4 and IPv6 traffic
- Develop practical packet-analysis and network-troubleshooting skills

## Investigations

| Investigation | Topics |
|---|---|
| DNS Analysis | DNS queries, A/AAAA records, DNS responses |
| ARP Analysis | ARP requests and replies, IPv4-to-MAC address resolution |
| TCP Three-Way Handshake | SYN, SYN/ACK, ACK, sequence numbers |
| TCP Connection Teardown | FIN, ACK, sequence numbers |
| TCP Reset | RST, RST/ACK, connection termination |
| ICMP / Ping Analysis | Echo requests, echo replies, TTL, round-trip time |
| DHCP | DORA Process | Packet Analysis | Configuration Verification |
| HTTP/HTTPS | Client Hello | Server Hello | Encrypted Application Data |
